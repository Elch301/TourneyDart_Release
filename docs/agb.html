4. Fairer Gebrauch und Schutz der Server

- bei Cloudshare höchstens 20 MB Upload je Konto und Monat, Dateien höchstens 30 Tage,
- Höchstgrößen für ein einzelnes Spielarchiv, eine Höchstzahl von Spielen, die ein Konto an einem Tag hochladen kann, sowie Höchstzahlen für Gruppen, Mitglieder und Statistikdaten,
- bei Spielen ohne oder mit sehr wenigen Würfen kann die Übertragung zum Server abgelehnt werden.
Die Grenzen sind so gewählt, dass normale Nutzung nicht eingeschränkt wird. Der Anbieter darf sie anpassen, wenn dies für den Betrieb nötig ist.
